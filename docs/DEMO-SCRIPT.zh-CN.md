# 黑客松 Demo 录制脚本（约 5 分钟）

开场（30 秒）：说明校园邮箱里的通知、附件和材料收集如何造成漏项。说清 Postbird 是 DeepSeek Harness 的本地优先工具集，本次新增了 Agent Skill 路由。不要称静态网页为真实邮箱演示。

第 1 幕（60 秒）：打开 [Live Demo](https://xplore-lab.github.io/postbird/demo/)，选“辅导员”或“学生组织”。展示模拟收件箱、今日简报、行动雷达、原邮件依据。

第 2 幕（60 秒）：展示材料追踪或线程回复，指出哪条邮件、哪份附件支持结论。展示回复草稿和人工复核位置，不点击真实发送。

第 3 幕（90 秒）：在已安装的 DSH 环境中展示 `SKILL.md` 如何指引 Agent 选择 `office_*` 工具。没有 DSH 环境时，如实说明，并用 `npm run demo` 展示本地输出的 XLSX、DOCX、PPTX 文件。打开产物核对内容。

第 4 幕（45 秒）：展示发件预览与确认边界、工作目录隔离，以及安装和 doctor 检查。结束时说明已实现与待接入项：NVIDIA / StepFun 当前未在仓库验证。

录制完成后，核对画面里没有真实邮箱地址、授权码和敏感附件，再上传 B 站。把公开视频 URL 填入提交表单。
